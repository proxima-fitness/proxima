# Bodybuilding Program Principles

Use this file when the user wants a **bodybuilding** or **hypertrophy** program: aesthetic focus, muscle building, PPL, upper/lower, bro split, or training by muscle group. Apply these principles when you select exercises (match names to list_exercises results) and build the week.

**Stimulus vs junk volume:** Weekly set landmarks below assume **hypertrophy-intended working sets** (challenging effort / ~0-3 RIR), not easy or untracked fluff. For the full framing of effective reps, RPE, deloads, and how this differs from tonnage, read `resources/stimulus-and-volume.md` whenever intensity or “what counts as volume” is in question.

## Shared principles

- **Priorities (never polish lower at expense of higher):** (1) adherence - days/week, session length, equipment, preferences. (2) volume / intensity / frequency. (3) progression. (4) exercise selection. (5) rest/tempo. Explicit user requests always win. If the request is outside these defaults, build what they asked and briefly note the tradeoff.
- **Split by days:** 2 → full body. 3 → full body (default) or upper/lower/full - not a 3-day bro split. If the user asks for a 3-day bro split, use it. 4 → upper/lower. 5 → upper/lower/push/pull/legs or rotating full body. 6 → PPL ×2. Hit each major muscle ≥2×/week. If the user forces 1×, use 1×.
- **Experience:** Beginners - less volume (near MEV), simple full-body or short splits, fixed reps on main lifts, linear/simple progression, no heavy periodization. Intermediates - MAV low-mid, rep ranges + double progression feel. Advanced - higher volume/variation OK. **Start at the low end of MAV**. More volume is a later tool, not the default.
- **Time budget:** ~45 min ≈ 12-16 working sets/day. ~60 min ≈ 16-22. ~90 min ≈ 24-30. If over budget, cut sets, superset accessories, or shorten isolation rest. Do not silently ship a 2-hour session.
- **Patterns each week:** squat, hinge, horizontal push, vertical push, horizontal pull, vertical pull. Add direct side-delt work for hypertrophy. Use long-length variants when you choose isolation (for example seated leg curl, incline/preacher curl, overhead triceps extension). Do not stack two heavy lower compounds (squat + deadlift) back-to-back on the same day.
- **Volume landmarks:** MEV = minimum for growth, MAV = best long-term gains, MRV = recoverable max. Values below are **weekly working sets** (hypertrophy-intended hard sets, excluding warmups) for intermediate lifters. Beginners use less. This is **not** sets×reps×weight in the program scorecard.
- **Per session:** 1-3 exercises per muscle, 8-12 sets per muscle per session max. Beyond that, systemic fatigue reduces efficiency.
- **Per week:** 2-5 different exercises per muscle. Match exercise IDs from list_exercises. Use titles below to find the right IDs.
- **Compound RPE (bodybuilding default):** For heavy **compound** lifts-especially barbell patterns such as bench press, squat, and deadlift, and similarly demanding compounds-**do not** prescribe sets above **~8.5 RPE** in typical hypertrophy blocks. Leave **1-2 reps in reserve**. Avoid grinders and true failure on these movements (injury risk).
- **Exception:** Slightly higher RPE on compounds is acceptable **only** when the program of the user includes **some strength emphasis** and **1RM testing** (for example a peaking or test week). Outside that context, keep compounds at or below ~8.5 RPE.

## Chest

- **Volume:** MEV 4-6, MAV 6-16, MRV 16-24 sets/week
- **Reps:** Compounds 8-12, isolation 10-20
- **Frequency:** 2-4x/week
- **Principle:** Include horizontal pressing, incline pressing, and isolation each week for complete development.
- **Horizontal pressing:** Medium Grip Bench Press, Wide Grip Bench Press, Flat Dumbbell Bench Press, Machine Chest Press, Smith Machine Bench Press
- **Incline pressing:** Incline Dumbbell Press, Incline Barbell Press Medium Grip, Incline Barbell Press Wide Grip, Incline Machine Chest Press, Smith Machine Incline Press
- **Isolation:** Flat Dumbbell Fly, Incline Dumbbell Fly, Cable Fly, Machine Fly, Pec Deck Fly

---

## Back

- **Volume:** MEV 6-10, MAV 10-20, MRV 20-30 sets/week
- **Reps:** Rows and weighted pullups 5-20, pulldowns/machine rows 10-30
- **Frequency:** 2-4x/week
- **Principle:** Spread volume roughly evenly between horizontal pulling (rows) and vertical pulling (pullups/pulldowns) each week.
- **Horizontal pulling:** Barbell Bent Over Row, Cambered Bar Row, Barbell Row to Chest, Underhand EZ Bar Row, Smith Machine Row, Chest Supported Row, Machine Chest Supported Row, T Bar Row, Incline Dumbbell Row, Two Arm Dumbbell Row, Single Arm Dumbbell Row, Hammer Low Row, Inverted Row, Seal Row, Seated Cable Row
- **Vertical pulling:** Normal Grip Pullup, Wide Grip Pullup, Parallel Grip Pullup, Underhand Pullup, Assisted variants, Normal/Wide/Parallel/Underhand/Narrow Grip Pulldown, Hammer High Row, Dumbbell Pullover, Machine Pullover, Straight Arm Pulldown

## Bicep

- **Volume:** MEV 8-10, MAV 14-20, MRV 20-26 sets/week
- **Reps:** 10-20 primary. Split the remainder between 5-10 and 20-30.
- **Frequency:** 3-6x/week (coordinate with back frequency. Heavy back reduces direct bicep need.)
- **Principle:** If back training is heavy (especially underhand), reduce direct bicep volume. For max size, include direct work on top of back training.
- **Exercises:** Alternating Dumbbell Curl, Barbell Curl Narrow/Normal Grip, Hammer Curl, Cable EZ Bar Curl, Machine Preacher Curl, Rope Twist Curl, Dumbbell Spider Curl, Dumbbell Twist Curl, Incline Dumbbell Curl, EZ Bar Curl/Preacher/Spider variants

---

## Tricep

- **Volume:** MEV 4-6, MAV 6-16, MRV 16-20 sets/week (direct work only. MV can be 0-4 because chest pressing already stimulates triceps.)
- **Reps:** 10-20 primary. JM Press/dips can go 5-10. Pushdowns can go 20-30.
- **Frequency:** 2-4x/week
- **Principle:** Include at least one compound (dips, and more) and one isolation (pushdowns, skull crushers) each week. If there is little or no pressing, increase tricep volume.
- **Exercises:** Barbell Triceps Overhead Extension, Assisted Dip, Barbell Skullcrusher, Cable Overhead Triceps Extension, Cable Single Arm Pushdown, Cable Triceps Pushdown, Dip, Dumbbell Skullcrusher, EZ Bar Overhead Triceps Extension, Machine Triceps Extension, Machine Triceps Pushdown, Rope Overhead Triceps Extension, Rope Pushdown, JM Press, Seated EZ Bar/Barbell Overhead Triceps Extension

---

## Quad

- **Volume:** MEV 4-6, MAV 6-14, MRV 14-18 sets/week
- **Reps:** Squats/hack squat 5-15, leg press 5-20, leg extension 10-30
- **Frequency:** 2-5x/week
- **Principle:** Include compound (squat, hack, leg press) and leg extension. More compound = lower reps. More isolation = higher reps.
- **Exercises:** High Bar Squat, Front Squat, Front Squat Cross Grip, Hack Squat, Leg Extension, Leg Press, Narrow Stance Squat, Feet Forward Smith Squat, Belt Squat

---

## Hamstring

- **Volume:** MEV 2-4, MAV 2-8, MRV 8-14 sets/week (start low. Hamstrings respond to low volume with good technique.)
- **Reps:** Hip hinges 5-10, leg curls 10-30
- **Frequency:** 2-3x/week
- **Principle:** Include both hip hinge (SLDL, good morning) and knee flexion (leg curls) each week for complete development.
- **Hip hinge:** Stiff Legged Deadlift, Dumbbell Stiff Legged Deadlift, High Bar Good Morning, Low Bar Good Morning, 45 Degree Back Raise
- **Knee flexion:** Lying Leg Curl, Seated Leg Curl, Single Leg Curl
- **Specialty:** Glute Ham Raise

---

## Glute

- **Volume:** MEV 6-8, MAV 8-24, MRV 24-30 sets/week (MV can be 0-6. Quads and hamstrings already train glutes.)
- **Reps:** Deadlifts 5-10, hip thrusts 10-20, lunges 20-30
- **Frequency:** 2-5x/week
- **Principle:** Include at least one compound (for example sumo/deficit deadlift), one hip thrust, and some lunge variation each week. More quad/ham volume reduces glute-specific need.
- **Hip thrust:** Barbell Hip Thrust, Machine Hip Thrust, Single Leg Hip Thrust, Dumbbell Single Leg Hip Thrust
- **Deadlift:** Deadlift, Sumo Deadlift, Sumo Deficit Deadlift, Deficit Deadlift, Trap Bar Deadlift
- **Lunge:** Barbell Walking Lunge, Dumbbell Walking Lunge, Reverse Lunge, Dumbbell Reverse Lunge, Split Squat, Dumbbell Split Squat
- **Specialty:** Cable Pull-Through, Machine Glute Kickback, Sumo Squat, Wide Stance Belt Squat
