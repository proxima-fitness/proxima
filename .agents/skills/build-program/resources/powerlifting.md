# Powerlifting

Apply these guidelines when you design or edit a powerlifting program (squat, bench, and deadlift focused).

---

## Principles

- **Specificity:** Prioritize squat, bench press, deadlift, and close variations. Avoid non-specific work (for example long runs, high-rep bodybuilding-only work). If the user asks for that work, include it.
- **Overload:** Use enough load to drive strength. Examples: heavy singles, doubles, triples, 5s, and controlled higher-rep work. Do not program only very light weights.
- **Recovery:** Deadlift least frequently, then squat, then bench. Avoid max deadlifts every day. Space the same lift types on non-consecutive days.
- **Variation:** Vary intensity and rep ranges over time. You can also vary lift variations. Do not use the same rep scheme indefinitely.
- **Individualization:** Match volume, frequency, and complexity to training level (beginner / intermediate / advanced). Add assistance for weak points when it fits (for example block pulls, pause work, accessories).

---

## Periodization (when relevant)

- **Macrocycle:** Long block (for example 8-16 weeks or a full season). Use this when the user mentions "program length", "meet prep", or "peaking".
- **Mesocycle:** 4-6 week blocks. These blocks often end with a rep-max test, a deload, or both.
- **Microcycle:** One week (7 days). Structure the week so squat, bench, and deadlift frequency and spacing match the guidelines below.

Introduce only as much periodization as fits the level and goals of the user. Keep beginner programs simple.

### RPE progression (8-week example)

Use this as a default **week-level** intensity guide for **~8-week** powerlifting macrocycles (meet prep, peaking blocks). If the user specifies different constraints, adjust.

#### Peak week placement

- **Default:** Use **one** week as the **peak** week. That week is the **week immediately before the final week** of the program, when that final week is **deload / taper / recovery** (the usual case). Do **not** label multiple weeks as “peak”. If the user wants multiple peak weeks, then label them as peak.
- **User override:** If the user specifies **which** week is peak (for example meet week, test week, or no deload after), **do not** keep the fixed week numbers from the example table. **Remap** week roles and RPE ceilings so intensity still progresses in a sensible way (base → build → optional reset/bridge → **peak** → easier final week if a deload or taper still exists).
- **Remapping:** Preserve the **relative order** of phases. Peak stays at the highest RPE. Weeks before peak ramp up. The week after peak drops. If the program ends on peak, that drop does not apply. Compress or stretch **earlier** weeks for shorter or longer programs. **Never** assign peak-level RPE to week 1 without user intent.

For an **8-week** program with **week 8** as **deload**, peak is **week 7** (second-to-last). The table below is an instance of that default.

| Week | Role | Main-lift RPE guidance |
|------|------|-------------------------|
| 1 | Base | **Max RPE 6** on hardest competition-style work |
| 2 | Build | **~6.5** |
| 3 | Build | **~7** |
| 4 | Build | **~7.5** |
| 5 | Reset / fatigue management | **~6 or ~6.5** (not a full deload). If the user asks for a full deload, use a full deload. |
| 6 | Bridge to peak | **~6-7** (cap hardest sets around **7**). If the user wants otherwise, use that request. |
| 7 | **Peak week** | Highest intensities / competition-specific work for the block |
| 8 | **Deload** | Reduced load, or reduced volume, or both. Easy technique and recovery. |

- **Scope:** These RPE ceilings apply to **main SBD / primary variation** work for that week. Accessories stay sub-max and purpose-driven (see **Accessory work (powerlifting)** below).
- **Other program lengths:** For **any** total week count **W** (1-based), when the **final** week is deload or taper, **peak week = week W − 1**. For blocks that are **not** ~8 weeks, **scale or interpolate**. For longer blocks, use a longer base or repeat a wave. For shorter blocks, **compress** the pattern. Do **not** jump to peak RPE in week 1. Do **not** place peak on the **last** week. If the user defines the last week as peak, place peak there and adjust deload or taper expectations to match.
- **Consistency with % and rep bands:** In **Sets, reps and loading** below, example **%** ranges are generic. For powerlifting blocks, **week-level RPE caps take precedence** when both appear. **Singles @ 90%+** and similar work belong in **late accumulation / peak**, not week 1.

## Exercise selection

- **Main lifts:** Squat, bench press, deadlift, and close variations (for example pause squats, block pulls, floor press, and more).
- **Deadlift vs Romanian deadlift:** Always prioritize **Deadlift (Barbell)** (conventional or sumo) over **Romanian Deadlift** for competition-specific hinge work. **Do not** program **Romanian Deadlift** as the **secondary compound** on a day. Do not use it in place of barbell deadlift when a deadlift-pattern compound fits. If the user asks for RDL, you can use RDL. Romanian deadlift can still appear as **assistance** after the two compounds if the user wants hamstring emphasis or has asked for it.
- **Assistance / accessories:** Use these for **identified** needs: weak points, joint/tissue tolerance, positioning/stability (for example block pulls, rows, tricep work). Do not use generic hypertrophy filler. **Undulate** volume and exercise choice across weeks and blocks (see **Accessory work** below). Moderate rep ranges (for example 8-12) are common for true accessories. Do **not** keep those ranges identical every session. Do not program accessories as max-effort singles.

---

## Accessory work (powerlifting)

- **Undulating accessory volume:** Vary **sets**, **exercise choice**, or both across **weeks** or **mesocycles**. Example: fewer accessory sets in heavier or intensity-focused weeks or blocks. If more accessory volume serves the plan in volume blocks, use more. Avoid repeating the **same** accessory prescription every training day or week (no “fixed 4×12 on everything” forever).
- **Align with main-lift phases:** In **peaking** or **high-intensity** SBD phases, **reduce** accessory volume. Use **minimal, targeted** work. In base or volume phases, accessories can be somewhat higher. They must still **not** be maximal generic hypertrophy.
- **Purpose-first selection:** Choose accessories for **identified** reasons: weak points, **joint/tissue tolerance** (for example triceps work to support elbows under heavy bench), stability/positioning, unilateral balance. Do not max out “pump” volume. Use **fewer** movements with clear **rationale**. Use exercise **`reason`** (and **`notes`** if needed) to state that rationale.
- **Not a hypertrophy split:** Do **not** program accessories like a bodybuilding split (high, uniform session accessory load) when the goal is **powerlifting** performance on the main lifts.

---

## Daily session structure (required)

- **Every training day** includes **two compound movements**: one **main** and one **secondary**. The main is the primary SBD lift or the closest competition variation for the focus of that day. The secondary is another SBD pattern, a variation, or a closely related multi-joint lift (for example pause squat, barbell row, close-grip bench, front squat). For hinge days, use **Deadlift (Barbell)**, block pulls, or deficit pulls. Do not use Romanian deadlift. If the user asked for RDL, you can use RDL.
- **Order:** Main compound first (heaviest / most specific), then secondary compound, then assistance and accessories.
- **Tempo:** Use different eccentric and pause prescriptions between main and secondary, or across weeks. This varies stimulus and manages fatigue. The build tools do not have a dedicated tempo field. Write tempo in **routine `notes`**, exercise **`notes`**, or exercise **`reason`**, or in more than one of these, so it is visible to the athlete.

## Frequency and placement (per week)

- **Deadlift:** Typically 1×/week (or 2× with one session lighter).
- **Squat:** Often 2×/week.
- **Bench:** Often 2-3×/week.

Space the same lift type on non-consecutive days. If the user wants more or less frequency, adjust. Then adjust volume per session to match.

### Days per week (4 vs 6)

- **4 days/week:** Fits the **two compounds per day** rule cleanly. Each session is main + secondary compound + accessories. Do not stack three competition lifts in one day.
- **6 days/week:** Do **not** make every day two heavy compounds. Total stress will be too high. Include **accessory- or volume-only days** (for example arms, upper back, calves, light pump work), or **lighter technique days** with reduced load or fewer hard sets, or both. A workable pattern is **four** “heavy” days (each with main + secondary compound + accessories) plus **two** easier days. Adjust to the recovery of the athlete. Keep those easier or accessory days **low-fatigue and targeted**. Do not use them as a standing slot for **high, steady** isolation volume every week.

---

## Sets, reps and loading

- **Heavy / specificity:** Include heavy work. Examples: singles @ 90%+, doubles/triples @ 80%+, sets of 5 @ 70-85%.
- **Variation / volume:** Include some 5s. You can also include 8-10 @ 60-75%. Assistance often falls in bands like 8-12 reps. **Undulate** set counts and rep ranges by week or block. Do not use the same assistance prescription every session.
- **Structuring:** Either (a) mix rep ranges in the week (concurrent), or (b) use blocks (for example 4 weeks hypertrophy, 4 weeks strength, 2-3 weeks of low-rep strength work). A **strength / low-rep block** can span multiple weeks. The **week-level RPE “peak”** in the table above is still **one** designated week. If the user asks for multiple peak-style weeks, you can use more than one. Match to the level and goals of the user.

---

## Example structures (reference only)

**Beginner:** 3 non-consecutive days (or 4 if the user prefers). **Each day:** one main compound + one secondary compound + optional accessories. Never put all three SBD competition lifts in one session. Example 3-day: Day 1 is Squat + Bench + accessories. Day 2 is Deadlift + row or light squat variation + accessories. Day 3 is Bench or squat emphasis + second compound + accessories. Progress linearly.

**Intermediate:** 4 days, for example upper/lower. Each day: main + secondary compound. Examples: lower is Squat + barbell row or light deadlift variation. Other lower is **Deadlift (Barbell)** + front squat or pause squat. Upper is Bench + close-grip or incline. Second upper is bench variation + row. If progress stalls, add variation (for example 3s, 8s, pause work).

**Advanced:** 5-6 days. If **6 days**, use **heavy** days with two compounds plus **lighter / accessory-only** days as in “Days per week (6)” above. Do not use six consecutive double-compound smash sessions. Example blocks: 4 weeks 8-10 reps, 4 weeks 4-6 reps, 2-3 weeks 1-3 reps (peaking). Re-test 1RMs and use them for the next cycle.

---

## When applying

- Before **buildWeek**, or when you build **mutateProgram** operations, make sure that **each powerlifting training routine** has **at least two compound exercises** that fit the main + secondary definition. If the user asked for something different, follow that request. **Do not** use Romanian Deadlift as a secondary compound. If the user requested RDL, you can use RDL. Use **Deadlift (Barbell)** for hinge compounds.
- Do **not** reduce a day to a single compound in a powerlifting program without clear user intent.
- Keep squat, bench, and deadlift emphasis and recovery (frequency and placement) in mind.
- Match day names to the split (for example "Squat", "Bench", "Lower", "Upper").
- If the user says "like 5/3/1" or "like Starting Strength", mirror that style. Still satisfy **two compounds per day** where those templates use a main lift plus a second barbell compound or clearly prescribed secondary work (for example FSL, supplemental lift). Use only exercise IDs from the exercise list. Do not invent IDs.
- In **buildWeek** and **mutateProgram** output, reflect **undulating** accessory load and **purpose** in **`reason`** / **notes** where useful. **Avoid** inflating accessory volume **uniformly** across all weeks. If the user asks for that, you can do it.
