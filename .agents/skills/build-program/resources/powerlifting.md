# Powerlifting

Apply these guidelines when designing or editing a powerlifting program (squat, bench, deadlift focused).

---

## Principles

- **Specificity:** Prioritise squat, bench press, deadlift (and close variations). Avoid non-specific work (e.g. long runs, high-rep bodybuilding-only work) unless the user asks for it.
- **Overload:** Use enough load to drive strength (e.g. heavy singles/doubles/triples, 5s, and controlled higher rep work). Don't program only very light weights.
- **Recovery:** Deadlift least frequently, then squat, then bench. Avoid max deadlifts every day; space same lift types on non-consecutive days.
- **Variation:** Vary intensity/rep ranges (and optionally variations) over time; don't do the same rep scheme indefinitely.
- **Individualisation:** Match volume, frequency and complexity to training level (beginner / intermediate / advanced). Add assistance for weak points (e.g. block pulls, pause work, accessories) as appropriate.

---

## Periodisation (when relevant)

- **Macrocycle:** Long block (e.g. 8–16 weeks or a full season). Use when the user mentions "program length", "meet prep", or "peaking".
- **Mesocycle:** 4–6 week blocks; often end with a rep-max test and/or deload.
- **Microcycle:** One week (7 days). Structure the week so squat/bench/deadlift frequency and spacing match the guidelines below.

Only introduce as much periodisation as fits the user's level and goals; keep beginner programs simple.

### RPE progression (8-week example)

Use this as a default **week-level** intensity guide for **~8-week** powerlifting macrocycles (meet prep, peaking blocks). Adjust if the user specifies different constraints.

#### Peak week placement

- **Default:** Use **one** week as the **peak** week: the **week immediately before the final week** of the program, when that final week is **deload / taper / recovery** (the usual case). Do **not** label multiple weeks as “peak” unless the user explicitly wants that.
- **User override:** If the user specifies **which** week should be peak (e.g. meet week, test week, or no deload after), **do not** keep the fixed week numbers from the example table—**remap** week roles and RPE ceilings so intensity still progresses sensibly (base → build → optional reset/bridge → **peak** → easier final week if a deload/taper still exists).
- **Remapping:** Preserve the **relative order** of phases (peak stays highest RPE; weeks before peak ramp up; the week after peak drops unless the program ends on peak). Compress or stretch **earlier** weeks for shorter or longer programs; **never** assign peak-level RPE to week 1 without user intent.

For an **8-week** program with **week 8** as **deload**, peak is **week 7** (second-to-last). The table below is an instance of that default.

| Week | Role | Main-lift RPE guidance |
|------|------|-------------------------|
| 1 | Base | **Max RPE 6** on hardest competition-style work |
| 2 | Build | **~6.5** |
| 3 | Build | **~7** |
| 4 | Build | **~7.5** |
| 5 | Reset / fatigue management | **~6 or ~6.5** (not a full deload unless the user asks) |
| 6 | Bridge to peak | **~6–7** (cap hardest sets around **7** unless user wants otherwise) |
| 7 | **Peak week** | Highest intensities / competition-specific work for the block |
| 8 | **Deload** | Reduced load and/or volume; easy technique and recovery |

- **Scope:** These RPE ceilings apply to **main SBD / primary variation** work for that week; accessories stay sub-max and purpose-driven (see **Accessory work (powerlifting)** below).
- **Other program lengths:** For **any** total week count **W** (1-based), when the **final** week is deload/taper, **peak week = week W − 1**. For blocks that are **not** ~8 weeks, **scale or interpolate** (e.g. longer blocks: longer base or repeat a wave); for shorter blocks, **compress** the pattern—do **not** jump to peak RPE in week 1. Do **not** place peak on the **last** week unless the user defines the last week as peak and adjusts deload/taper expectations accordingly.
- **Consistency with % and rep bands:** In **Sets, reps and loading** below, example **%** ranges are generic; for powerlifting blocks, **week-level RPE caps take precedence** when both appear. **Singles @ 90%+** and similar work belong in **late accumulation / peak**, not week 1.

## Exercise selection

- **Main lifts:** Squat, bench press, deadlift (and close variations: pause squats, block pulls, floor press, etc.).
- **Deadlift vs Romanian deadlift:** Always prioritise **Deadlift (Barbell)** (conventional or sumo) over **Romanian Deadlift** for competition-specific hinge work. **Do not** program **Romanian Deadlift** as the **secondary compound** on a day (and do not use it in place of barbell deadlift when a deadlift-pattern compound is appropriate) **unless the user explicitly asks for RDL.** Romanian deadlift may still appear as **assistance** after the two compounds if the user wants hamstring emphasis or has asked for it.
- **Assistance / accessories:** For **identified** needs—weak points, joint/tissue tolerance, positioning/stability (e.g. block pulls, rows, tricep work)—not generic hypertrophy filler. **Undulate** volume and exercise choice across weeks/blocks (see **Accessory work** below). Moderate rep ranges (e.g. 8–12) are common for true accessories but should **not** be identical every session; don't program accessories as max-effort singles.

---

## Accessory work (powerlifting)

- **Undulating accessory volume:** Vary **sets and/or exercise choice** across **weeks** or **mesocycles** (e.g. fewer accessory sets in heavier or intensity-focused weeks or blocks; more in volume blocks **only when** it serves the plan). Avoid repeating the **same** accessory prescription every training day or week (no “fixed 4×12 on everything” forever).
- **Align with main-lift phases:** In **peaking** or **high-intensity** SBD phases, **reduce** accessory volume and favour **minimal, targeted** work. In base/volume phases, accessories can be somewhat higher but still **not** maximal generic hypertrophy.
- **Purpose-first selection:** Choose accessories for **identified** reasons—weak points, **joint/tissue tolerance** (e.g. triceps work to support elbows under heavy bench), stability/positioning, unilateral balance—not to max out “pump” volume. Prefer **fewer** movements with clear **rationale**; use exercise **`reason`** (and **`notes`** if needed) to state that rationale.
- **Not a hypertrophy split:** Do **not** program accessories like a bodybuilding split (high, uniform session accessory load) when the goal is **powerlifting** performance on the main lifts.

---

## Daily session structure (required)

- **Every training day** includes **two compound movements**: one **main** (primary SBD or closest competition variation for that day’s focus) and one **secondary** compound (another SBD pattern, variation, or closely related multi-joint lift—e.g. pause squat, barbell row, close-grip bench, front squat; for hinge days prefer **Deadlift (Barbell)**, block pulls, or deficit pulls—not Romanian deadlift unless the user asked for RDL).
- **Order:** Main compound first (heaviest / most specific), then secondary compound, then assistance and accessories.
- **Tempo:** Use different eccentric and pause prescriptions between main and secondary, or across weeks, to vary stimulus and manage fatigue. The build tools do not have a dedicated tempo field—write tempo in **routine `notes`**, exercise **`notes`**, and/or exercise **`reason`** so it is visible to the athlete.

---

## Frequency and placement (per week)

- **Deadlift:** Typically 1×/week (or 2× with one session lighter).
- **Squat:** Often 2×/week.
- **Bench:** Often 2–3×/week.

Space the same lift type on non-consecutive days. Adjust if the user explicitly wants more or less frequency (then adjust volume per session accordingly).

### Days per week (4 vs 6)

- **4 days/week:** Fits the **two compounds per day** rule cleanly: each session is main + secondary compound + accessories without stacking three competition lifts in one day.
- **6 days/week:** Do **not** make every day two heavy compounds—total stress will be too high. Include **accessory- or volume-only days** (e.g. arms, upper back, calves, light pump work) and/or **lighter technique days** with reduced load or fewer hard sets. A workable pattern is **four** “heavy” days (each with main + secondary compound + accessories) plus **two** easier days; adjust to the athlete’s recovery. Keep those easier/accessory days **low-fatigue and targeted**, not a standing slot for **high, steady** isolation volume every week.

---

## Sets, reps and loading

- **Heavy / specificity:** Include heavy work, e.g. singles @ 90%+, doubles/triples @ 80%+, sets of 5 @ 70–85%.
- **Variation / volume:** Include some 5s, and optionally 8–10 @ 60–75%. Assistance often falls in bands like 8–12 reps, but **undulate** set counts and rep ranges by week or block—don’t use the same assistance prescription every session.
- **Structuring:** Either (a) mix rep ranges in the week (concurrent), or (b) use blocks (e.g. 4 weeks hypertrophy, 4 weeks strength, 2–3 weeks of low-rep strength work). A **strength / low-rep block** can span multiple weeks, but the **week-level RPE “peak”** in the table above is still **one** designated week unless the user asks for multiple peak-style weeks. Match to user's level and goals.

---

## Example structures (reference only)

**Beginner:** 3 non-consecutive days (or 4 if the user prefers). **Each day:** one main compound + one secondary compound + optional accessories—never all three SBD competition lifts in one session. Example 3-day: Day 1 Squat + Bench + accessories; Day 2 Deadlift + row or light squat variation + accessories; Day 3 Bench or squat emphasis + second compound + accessories. Progress linearly.

**Intermediate:** 4 days, e.g. upper/lower. Each day: main + secondary compound (e.g. lower: Squat + barbell row or light deadlift variation; other lower: **Deadlift (Barbell)** + front squat or pause squat; upper: Bench + close-grip or incline; second upper: bench variation + row). Add variation (e.g. 3s, 8s, pause work) when progress stalls.

**Advanced:** 5–6 days. If **6 days**, use **heavy** days with two compounds plus **lighter / accessory-only** days as in “Days per week (6)” above—not six consecutive double-compound smash sessions. Example blocks: 4 weeks 8–10 reps, 4 weeks 4–6 reps, 2–3 weeks 1–3 reps (peaking). Re-test 1RMs and use for next cycle.

---

## When applying

- Before **buildWeek** or when building **mutateProgram** operations: ensure **each powerlifting training routine** has **at least two compound exercises** that fit the main + secondary definition (unless the user explicitly asked for something different). **Do not** use Romanian Deadlift as a secondary compound unless the user explicitly requested RDL; prefer **Deadlift (Barbell)** for hinge compounds.
- Do **not** reduce a day to a single compound in a powerlifting program without clear user intent.
- Keep squat/bench/deadlift emphasis and recovery (frequency/placement) in mind.
- Match day names to the split (e.g. "Squat", "Bench", "Lower", "Upper").
- If the user says "like 5/3/1" or "like Starting Strength", mirror that style while still satisfying **two compounds per day** where those templates use a main lift plus a second barbell compound or clearly prescribed secondary work (e.g. FSL, supplemental lift). Use only exercise IDs from the exercise list; don't invent IDs.
- In **buildWeek** and **mutateProgram** output, reflect **undulating** accessory load and **purpose** in **`reason`** / **notes** where useful; **avoid** inflating accessory volume **uniformly** across all weeks unless the user asks for that.
