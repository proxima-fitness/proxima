# Powerlifting

Apply these guidelines when designing or editing a powerlifting program (squat, bench, deadlift focused).

---

## Principles

- **Specificity:** Prioritise squat, bench press, deadlift (and close variations). Avoid non-specific work (e.g. long runs, high-rep bodybuilding-only work) unless the user asks for it.
- **Overload:** Use enough load to drive strength (e.g. heavy singles/doubles/triples, 5s, and controlled higher rep work). Don't program only very light weights.
- **Recovery:** Deadlift least frequently, then squat, then bench. Avoid max deadlifts every day; space same lift types on non-consecutive days.
- **Variation:** Vary intensity/rep ranges (and optionally variations) over time; don't do the same rep scheme indefinitely.
- **Individualisation:** Match volume, frequency and complexity to training level (beginner / intermediate / advanced). Add assistance for weak points (e.g. block pulls, pause work, accessories) as appropriate.

---

## Periodisation (when relevant)

- **Macrocycle:** Long block (e.g. 8–16 weeks or a full season). Use when the user mentions "program length", "meet prep", or "peaking".
- **Mesocycle:** 4–6 week blocks; often end with a rep-max test and/or deload.
- **Microcycle:** One week (7 days). Structure the week so squat/bench/deadlift frequency and spacing match the guidelines below.

Only introduce as much periodisation as fits the user's level and goals; keep beginner programs simple.

---

## Exercise selection

- **Main lifts:** Squat, bench press, deadlift (and close variations: pause squats, block pulls, floor press, etc.).
- **Assistance / accessories:** For weak points and support (e.g. block pulls, glute bridges, tricep work, rows). Use moderate rep ranges (e.g. 8–12) for these; don't program them as max-effort singles.

---

## Frequency and placement (per week)

- **Deadlift:** Typically 1×/week (or 2× with one session lighter).
- **Squat:** Often 2×/week.
- **Bench:** Often 2–3×/week.

Space the same lift type on non-consecutive days. Adjust if the user explicitly wants more or less frequency (then adjust volume per session accordingly).

---

## Sets, reps and loading

- **Heavy / specificity:** Include heavy work, e.g. singles @ 90%+, doubles/triples @ 80%+, sets of 5 @ 70–85%.
- **Variation / volume:** Include some 5s, and optionally 8–10 @ 60–75%. Assistance often 8–12 reps.
- **Structuring:** Either (a) mix rep ranges in the week (concurrent), or (b) use blocks (e.g. 4 weeks hypertrophy, 4 weeks strength, 2–3 weeks peaking). Match to user's level and goals.

---

## Example structures (reference only)

**Beginner:** 3 non-consecutive days. Each day: Squat 3×5, Bench 3×5, Deadlift 1×5. Progress linearly; optional light day for squat/deadlift as needed.

**Intermediate:** 4 days, e.g. upper/lower. Lower: Squat 5×5, Deadlift 1×5 one day; Squat heavy 5, Deadlift 3×5 lighter another. Upper: Bench 5×5 + tricep/back work; second bench day heavy 5 + pull-ups. Add variation (e.g. 3s, 8s, pause squats) when progress stalls.

**Advanced:** 5–6 days, lift-focused. Dedicated days for squat, bench, deadlift; optional extra bench day. Example blocks: 4 weeks 8–10 reps, 4 weeks 4–6 reps, 2–3 weeks 1–3 reps (peaking). Re-test 1RMs and use for next cycle.

---

## When applying

- Keep squat/bench/deadlift emphasis and recovery (frequency/placement) in mind.
- Match day names to the split (e.g. "Squat", "Bench", "Lower", "Upper").
- If the user says "like 5/3/1" or "like Starting Strength", mirror that style (e.g. 5/3/1: main work + FSL/joker; SS: 3×5 full body). Use only exercise IDs from the exercise list; don't invent IDs.
