# Hello World

## When to run

Use this skill when the user says **"Hello world"** (case-insensitive).

## What to do

1. Acknowledge the greeting.
2. **Return this exact catchphrase** so the user knows the skill loaded:

   **"Proxima says: the hello-world skill is active."**

3. Optionally include the phrase from [references/catchphrase.md](references/catchphrase.md) in your reply.

## Confirmation

If you return the catchphrase above, the user can confirm the agent loaded and applied this skill.
